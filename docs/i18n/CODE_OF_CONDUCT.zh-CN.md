# 行为准则

## 我们的承诺

我们承诺让每个人的参与都受到尊重、免于骚扰,不论其背景、身份、经验或个人特征。

## 期望的行为

保持建设性,在核实主张的同时假定善意,尊重隐私,并把批评留给工作与决策本身。骚扰、威胁、人肉搜索、歧视,以及不受欢迎的性关注,都不可接受。

## 本仓特别请求的一件事

这个项目的存在,是为了让一个陌生人能够校验并非由他构建的字节。而这只有在「摘要对不上」这类报告**被欢迎而不是被辩驳**时才成立。请把不一致带来:你校验的版本、你算出的值、以及你从哪里取得该文件。在这里,没有人需要先说服别人才会被认真对待;一份最后被证明是本地失误的报告不花费任何东西——另一种情形是,一位读者察觉到了什么,却什么也没说。

## 执行

请将行为方面的关切私下报告给仓库维护者。维护者可以移除内容、限制参与,或采取其它相称的措施。报告将被审慎处理,并受法律与安全需要的约束。

本政策改编自 Contributor Covenant 2.1 的原则,未纳入外部联系方式。
